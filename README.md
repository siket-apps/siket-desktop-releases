## ✨ Overview

**Siket Desktop** brings the complete Siket experience to your operating system with the speed, polish, and comfort of a native app. Built for makers, thinkers, and teams who want to protect their attention and do meaningful work without browser distractions.

- ⚡ **Instant & Responsive** — Open instantly with global keyboard shortcuts, zero tab clutter, and rapid search.
- 🎯 **Deep Focus Workspaces** — Minimalist, clean UI designed to keep your attention on one task at a time.
- 🪄 **System Tray Quick Capture** — Drop ideas and tasks directly from your menu bar or taskbar without breaking your flow.
- 🔄 **Seamless Cloud Sync** — Continuous, offline-resilient sync across desktop and web sessions.
- 🎨 **Native Aesthetics** — macOS vibrancy, modern dark-mode palette, and tailored window controls.

### macOS Setup

1. Download the [Universal macOS Installer (`.dmg`)](https://release.siket.app/mac).
2. Open the downloaded `.dmg` file.
3. Drag the **Siket** icon into your **Applications** folder.
4. Launch Siket from Spotlight or Launchpad.

### Windows Setup

1. Download the [Windows Setup (`.exe`)](https://release.siket.app/windows).
2. Run the installer and follow the quick setup wizard.
3. Siket will automatically launch and add a shortcut to your Start Menu and Desktop.

### Linux Setup

1. Download the [Linux AppImage](https://release.siket.app/linux).
2. Make the file executable:
   ```bash
   chmod +x Siket-linux.AppImage
   ```
3. Run it directly or integrate with your desktop app launcher:
   ```bash
   ./Siket-linux.AppImage
   ```
