## [2.0.0] - 2026-10-31

### 🎉 Initial Public Release

Welcome to the official stable release of **Siket Desktop 2.0**! This milestone delivers a dedicated, native application for macOS, Windows, and Linux.

### ✨ Highlights & Features

- **Multi-Platform Support**:
  - **macOS**: Native Universal build supporting both Apple Silicon (M1/M2/M3/M4) and Intel architectures.
  - **Windows**: Modern 64-bit installer with desktop and Start Menu shortcuts.
  - **Linux**: Universal, portable AppImage for Ubuntu, Debian, Fedora, Arch, and derivatives.

- **Deep Focus Workspace**:
  - Calm, modern interface built to minimize cognitive load.
  - Dark-mode aesthetics tuned with subtle glows, glassmorphism, and responsive layouts.
  - Distraction-free full-screen and distraction-free window modes.

- **System Tray & Quick Capture**:
  - Global menu bar / system tray popover for rapid note-taking, task capture, and timer controls.
  - Minimize to tray option to keep Siket always ready without cluttering your taskbar.

- **Unified Authentication & Handoff**:
  - Seamless session handoff from the Siket web app to desktop.
  - Secure passkey, email, and Google authentication support with automatic token refresh.

- **Auto-Update Engine**:
  - Integrated update feed via `release.siket.app`.
  - Silent background checking for new releases with one-click restart updates.

- **Direct Download Infrastructure**:
  - Clean canonical download routes:
    - `/mac` for macOS Universal Installer (`.dmg`)
    - `/windows` for Windows Installer (`.exe`)
    - `/linux` for Linux AppImage (`.AppImage`)
